# 실시간 비교 대시보드와 녹화

[설치 안내](INSTALL.ko.md) · [English](DEMO.en.md)

**현재 상태:** 로컬 대시보드와 실행 안내를 제공하며, 실제 실행을 화면 녹화한 영상은 아직 공개하지 않았습니다.

대시보드는 실제 **경로 선택 → 로컬 근거 회수 → 구조화 산출물 생성** 과정을 보여 줍니다. 외부 사이트의 버튼을 누르는 브라우저 자동화 시험이 아닙니다. 브라우저는 로컬 진행 화면을 표시하고 모델 호출은 Node 평가기가 수행합니다. 이 영상으로 측정한 업무 흐름은 설명할 수 있지만 모든 browser-use가 빨라진다는 주장을 할 수는 없습니다.

## 과금 없이 준비

설치와 비공개 `.env` 설정을 마친 뒤 실행합니다.

```sh
node --use-system-ca -- benchmarks/complex-mission-eval.mjs --preflight
node --use-system-ca -- benchmarks/live-demo-server.mjs --run-id public-demo-01 --env-file .env --port 8786
```

실행마다 `public-demo-01`처럼 새로운 run ID를 사용합니다. 소문자 또는 숫자로 시작하고 소문자·숫자·하이픈만 사용하며 48자 이하여야 합니다. 위 예제의 출력 폴더는 `benchmarks/results/live-demo-public-demo-01/`입니다. 기존 보고서는 덮어쓰지 않습니다.

브라우저에서 [로컬 대시보드](http://127.0.0.1:8786/)를 엽니다. 서버를 켜는 것만으로 추론을 시작하지 않습니다. HTTP 화면은 읽기만 가능하므로 페이지 요청으로 유료 실행을 시작할 수 없습니다. `.env`, 비밀 값이 있는 터미널, 계정 화면, 비공개 업무 파일은 녹화 영역에서 제외합니다.

## 실제 실행과 녹화

1. 대시보드 창을 보이게 하고 읽기 좋은 크기로 맞춥니다. 녹화 도구에서 그 창을 선택한 뒤 미리보기가 검은 화면이 아닌지 확인합니다.
2. 추론 전에 녹화를 시작합니다. 서버 터미널에 `run`을 입력하고 Enter를 누릅니다. 예상 비용 예약 $5와 POST 80회 상한을 가진 **유료** 비교가 시작됩니다.
3. 완료 또는 실패까지 녹화를 유지합니다. 세 방식은 동시에 실행되지 않고 순서를 바꿔 가며 순차 실행됩니다. 업무별 체크포인트가 기록될 때 화면 수치가 갱신됩니다.
4. 생성된 `report.json`, `report.json.manifest.json`과 영상을 함께 보관합니다. 평가가 끝난 뒤 터미널에 `quit`을 입력하면 서버를 종료합니다.

서버 명령에 `--run`을 붙이면 유료 평가기를 바로 시작할 수 있습니다. 서버 자체에는 영상 캡처 기능이 없으므로 별도의 녹화 도구를 사용합니다. 수동으로 재구성한 대시보드 재생을 실제 추론 영상으로 표현하지 마세요. 요청 중 서버를 종료하면 결과가 불명확한 시도가 남을 수 있으며, 공급자 과금이 없었다는 뜻은 아닙니다.

## 화면 수치 읽기

- **새 업무:** 합성 임무 2개 × 기본/근거 변경 × 방식 3개로 새로운 최종 산출물 12개를 만듭니다.
- **정확 재생:** 동일한 결과를 재사용하는 기록 6개가 추가됩니다. 신규 호출과 비용은 0이어야 하지만 원본 생성 비용은 앞에서 이미 발생했습니다.
- **핵심·엄격 품질:** 핵심은 구조·선정·계산·마감·승인 선행 조건입니다. 엄격 품질은 고정된 인용 집합 검사까지 포함합니다. 빠르게 틀린 결과를 성공한 작업의 속도 향상으로 세지 않습니다.
- **비용:** JEV 입력 정가 추정과 OpenRouter 보고 크레딧 차감 합계입니다. 호스트 추론·충전 수수료·세금·녹화·후속 도구는 제외합니다. `null`은 무료가 아니라 알 수 없다는 뜻입니다.
- **캐시:** 근거가 바뀌면 최종 산출물을 다시 생성합니다. 프롬프트 캐시 토큰은 공급자 입력 재사용이며 답안 재사용이나 무료 출력 생성이 아닙니다. 첫 요청도 공급자 캐시가 비어 있다고 보장하지 않습니다.

평가기의 작업은 로컬 분석뿐입니다. 실제 신청·게시·연락·외부 웹사이트 조작은 하지 않습니다. 모든 방식의 최종 생성기는 Astra입니다. 적응형의 자료 선택 모델은 신뢰할 설정과 관측 조건이 충족될 때만 달라질 수 있습니다.

## 결과를 공개할 때

원래 시간·실패 행·고정 manifest를 보존합니다. 배속 편집에는 배속을 표시하고 실제 소요 시간을 주장할 때는 편집하지 않은 1배속 영상도 제공합니다. 영상과 자체 보고서에 비공개 내용이 없는지 확인한 뒤 공개합니다. 저장소에 합성 자료가 있다는 사실이 사용자의 임의 입력까지 공개해도 된다는 뜻은 아닙니다.

기존 [복잡한 임무 보고서](../benchmarks/results/complex-missions-v1/RESULTS.md)는 완료된 별도 실측입니다. 새 녹화의 비용·점수로 기존 수치를 재사용하지 마세요. 새 영상에는 그 실행에서 생성된 보고서를 연결해야 합니다.
