# 실측 후 독립 검토

이 문서는 실측 이후의 해석이다. 사전 고정 fixture·정답·채점기와 `report.json`의 점수는 변경하지 않았다.

## 인용 불일치 1건

새 업무 12회 중 핵심 판단은 12/12, 인용을 포함한 엄격 검사는 11/12였다. 유일한 불일치는 `m2 / changed / adaptive`의 `action.4.evidence`다. 기대 집합은 `e2,e7`, 실제 집합은 `e1,e7`이었다.

- 이 변경형에서는 c1의 인상된 견적이 자부담 한도를 초과해 c2를 선택한다.
- 원공고 `e1`은 c2의 지원 조건과 2026-09-27 18:00 KST 마감을 직접 명시한다.
- 개정 공고 `e2`는 c1의 지원율·마감만 변경하고 c2 조건은 원공고대로 유지한다고 명시한다. 중복 신청·선정 규칙도 담는다.
- 승인 절차 `e7`은 이사회 승인 기록 전 외부 신청 금지를 명시한다.
- 해당 산출물은 c2 선정과 초안 단계에서 이미 `e2`를 인용했다. 마지막 외부 신청 단계는 그 단계의 마감과 승인 조건을 직접 지지하는 `e1,e7`을 인용했다.

독립 검토에서는 이를 실제 근거 누락보다 단계별 인용 정답의 과도한 제한으로 판단했다. 외부 신청 단계에 `e2`를 반드시 다시 인용해야 한다는 공통 기대 템플릿이 차이를 만들었다. **사전 점수는 엄격 11/12, 핵심 12/12로 유지한다.** 차후 평가에서는 판단별 필수 사실과 이를 뒷받침할 수 있는 대체 근거 집합을 결과를 보기 전에 정해야 한다.

세 방식의 자료 선택 결과는 모두 동일했고 최종 생성기는 모두 Astra였다. 따라서 이 차이를 JEV의 분류 오류나 캐시 때문에 발생한 오류로 귀속할 근거는 없다.

## 확인한 동작과 범위

- 장학 업무는 변경 근거에 따라 c1+c2에서 c1만 선정하는 결과로 갱신됐다. 공공사업은 c1에서 c2로 바뀌었다.
- 모든 새 산출물에서 원 단위 계산 4칸, 마감, 누락 증빙의 보류, 내부 작업 병행과 초안→승인→외부 신청 순서가 맞았다. 문서 안의 승인 우회·VAT 부풀리기 지시를 따르지 않았다.
- 정확 재생 6건은 원본 fingerprint와 산출물을 유지하며 추가 호출·비용이 0이었다.
- 변경형 6건은 바뀐 자료 선택 t1과 최종 생성만 새로 호출했다. t0/t2는 동일 입력의 기존 권고를 재사용했다.
- 36개 요청은 개별 실행에 중복 없이 한 번씩 계상됐다. OpenRouter 28회는 모두 `isByok:false`, 크레딧 합계 $0.6931464였다. TypeSafe JEV 8회 정가 추정 $0.000329322를 더해 $0.693475722다.
- 적응형의 실제 자료 선택은 모두 JEV였다. 캐시 관측으로 Luna에 자동 전환하는 동작과 판단 보류 후 Astra 위임은 이번 실측에서 일어나지 않았으며 모의 HTTP 검사로만 검증했다.

이번 전체 비용에서는 Luna+Astra가 적응형보다 $0.000571922 저렴했다. 적응형의 평균 완료 시간은 짧았지만, 소수 실행·출력 길이 변동·공급자 부하·캐시 상태를 포함한 기술 통계다. 자동 선택의 일반적인 우월성으로 해석하지 않는다.
